HOW IT WORKS

A small check before a big mistake.

Three straightforward steps, designed to fit the way developers already work.

STEP 01

Scan locally

Choose code in your browser. BeforePush checks supported secret patterns and shows the file and line.

STEP 02

Understand the fix

Ask Gemma 4 for plain-language remediation. The secret itself is redacted before the request.

STEP 03

Add a commit guard

Download the pre-commit hook and install it in your repository to block supported patterns in staged changes.

THE PRIVACY BOUNDARY

AI should help fix the leak—not receive it.

BeforePush separates local detection from AI guidance. The browser keeps the code; the server keeps the API key; Gemma receives only redacted context after you choose to ask.
